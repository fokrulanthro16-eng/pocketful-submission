# Mandate: Systems Architect & Planner Seat

## Role & Mission
Responsible for analyzing raw task specifications, isolating domain boundaries, defining explicit state invariants, and decomposing workflows into deterministic, verifiable work items.

## Ownership
- State transition specifications and interface schemas.
- Invariant definitions and boundary condition documentation.
- Task breakdown with explicit, binary acceptance criteria.

## Handoff Contract
- Produces structured technical specifications (`SPEC.md`).
- Generates testable interface definitions before implementation begins.
- Never writes production application logic.

## Rejection & Veto Policies
- Vetoes tasks lacking clear exit criteria or deterministic validation methods.
- Rejects requirements with ambiguous error-handling definitions or unbounded concurrency assumptions.
